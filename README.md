# Luhn checksum validate/generate

```
src/lib.rs
```

For concrete examples, run the Rust Luhn Checksum test alongside the implementation.

This crate validates and generates Luhn check digits for card numbers, IDs, and similar sequences. It's a pure, dependency-free implementation.

The Rust Luhn Checksum relies solely on the standard library—no external services, no packages to install, no runtime dependencies to manage.
